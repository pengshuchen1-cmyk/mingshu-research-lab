## 🎯 快速开始（3 分钟）

### 最简单方式：Streamlit Cloud（免费）

1. **运行部署检查**
```bash
cd bazi_ziwei_app
python3 check_deployment.py
```

2. **清理敏感文件**
```bash
rm -rf data/*.db logs/*.log
```

3. **推送到 GitHub**
```bash
git add .
git commit -m "准备部署"
git push
```

4. **部署到 Streamlit Cloud**
- 访问：https://share.streamlit.io
- 连接你的 GitHub 仓库
- 选择主文件：`bazi_ziwei_app/app.py`
- 配置环境变量：
  ```
  MINGSHU_RUNTIME_MODE=public
  MOONSHOT_API_KEY=你的Kimi密钥（可选）
  ```
- 点击 Deploy，等待 2-3 分钟

**完成！** 你会得到一个 `https://你的应用.streamlit.app` 地址

## 🚀 三种部署方案对比

### 方案 A：Streamlit Cloud（推荐新手）

**适合：** 个人项目、演示、快速上线

**优点：**
- ✅ 完全免费
- ✅ 零配置，3 分钟部署
- ✅ 自动 HTTPS
- ✅ 自动更新（git push 即部署）

**缺点：**
- ❌ 资源限制（1GB 内存）
- ❌ 必须公开 GitHub 仓库
- ❌ 不能持久化数据库（只能用公网模式）

**成本：** ¥0/月

---

### 方案 B：Docker 部署（推荐生产）

**适合：** 正式运营、需要持久化数据

**步骤：**
```bash
# 1. 运行检查
python3 check_deployment.py

# 2. 构建并启动（公网模式）
docker-compose up -d

# 3. 查看日志
docker-compose logs -f

# 4. 访问
open http://localhost:8501
```

**优点：**
- ✅ 环境隔离，稳定可靠
- ✅ 支持本地模式（保存命盘）
- ✅ 易于迁移和扩展
- ✅ 支持自动重启

**缺点：**
- ❌ 需要自己购买服务器
- ❌ 需要基础 Docker 知识

**成本：** ¥60-200/月（服务器费用）

---

### 方案 C：VPS 传统部署

**适合：** 有云服务器经验的开发者

**一键部署：**
```bash
# 在服务器上运行
wget https://你的仓库/deploy.sh
bash deploy.sh
```

脚本会自动：
- 安装 Python 3.11
- 配置虚拟环境
- 安装依赖
- 创建 systemd 服务
- 配置 Nginx 反向代理
- 可选配置 HTTPS

**优点：**
- ✅ 完全控制服务器
- ✅ 可以自定义优化
- ✅ 支持大规模部署

**缺点：**
- ❌ 需要运维知识
- ❌ 手动维护更新

**成本：** ¥60-400/月（服务器费用）

---

## ⚙️ 运行模式说明

### 公网模式（MINGSHU_RUNTIME_MODE=public）

**特点：**
- 不保存命盘到数据库
- 用户数据在会话内存中（30分钟失效）
- 自动阻断数据库文件访问
- 适合公开网站

**环境变量：**
```bash
MINGSHU_RUNTIME_MODE=public
MOONSHOT_API_KEY=sk-xxx  # 可选
```

---

### 本地模式（MINGSHU_RUNTIME_MODE=local）

**特点：**
- 命盘持久化保存到 SQLite
- 支持命盘档案功能
- 支持数据备份和导入
- 适合私有部署、内网使用

**环境变量：**
```bash
MINGSHU_RUNTIME_MODE=local
MOONSHOT_API_KEY=sk-xxx  # 可选
```

## 🔒 安全注意事项

### 公网部署必须做：

1. **清理敏感文件**
```bash
# 运行检查脚本
python3 check_deployment.py

# 手动清理
rm -rf data/*.db data/*backup* logs/
```

2. **设置正确的环境变量**
```bash
export MINGSHU_RUNTIME_MODE=public
```

3. **不要在代码中硬编码密钥**
- ✅ 使用环境变量
- ✅ 使用 `.streamlit/secrets.toml`（不提交到 Git）
- ❌ 不要写在代码里

4. **配置 .gitignore**
```
data/*.db
logs/
.streamlit/secrets.toml
.env
```

## 🛠️ 常用命令速查

### Docker 部署
```bash
# 启动
docker-compose up -d

# 停止
docker-compose down

# 查看日志
docker-compose logs -f

# 重启
docker-compose restart

# 更新代码后重新部署
git pull
docker-compose down
docker-compose build
docker-compose up -d
```

### VPS 部署
```bash
# 查看服务状态
sudo systemctl status mingshu

# 启动/停止/重启
sudo systemctl start mingshu
sudo systemctl stop mingshu
sudo systemctl restart mingshu

# 查看日志
sudo journalctl -u mingshu -f

# 查看最近 100 行错误日志
sudo journalctl -u mingshu -p err -n 100
```

## 📞 遇到问题？

### 常见问题快速解决

**问题 1：端口被占用**
```bash
# 查看占用进程
lsof -i :8501

# 杀死进程
kill -9 <PID>
```

**问题 2：依赖安装失败**
```bash
# 升级 pip
pip install --upgrade pip

# 重新安装
pip install -r requirements.txt --force-reinstall
```

**问题 3：Docker 构建慢**
```bash
# 使用国内镜像
export DOCKER_BUILDKIT=1
docker build --network=host -t mingshu-app .
```

**问题 4：页面打不开**
```bash
# 检查服务状态
systemctl status mingshu

# 检查防火墙
sudo ufw status
sudo ufw allow 8501
```
