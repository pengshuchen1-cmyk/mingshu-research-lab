# 命数研究室隐私说明

## 我们处理哪些资料

建立个人命盘时，用户可以填写性别、出生日期和出生时间。称呼可选，建议使用昵称。排盘统一使用中国标准时间。

## 用途与保存时间

上述资料会传至本站服务器内存用于排盘、报告和问答，保存范围为“仅本次会话”，不写入公网服务器命盘数据库，不用于广告、用户画像或第三方统计。本次会话 30 分钟无操作后，原始资料、派生结果和 AI 对话会一并清除；切换命盘也会清空对话。

## AI 问答与云端处理

当前 AI 问答仅支持当前四柱相关问题。未配置云端服务时，问答由本地规则直接产生。开启云端分析时，云端只接收与当前问题有关的去身份化事实包、由本地规则生成的结论计划，以及必要会话摘要；必要会话摘要最多取最近 6 条清理后的对话，不包含未经清理的完整会话原文。原始生日、姓名、地点、联系方式和密钥不会发送给 Kimi；经度、档案编号和内部版本同样不会发送。

使用 Kimi 时，请求通过 Moonshot 的 OpenAI 兼容 Chat Completions 接口发送，并要求返回符合本项目 JSON Schema 的结构化内容；该接口不使用 OpenAI Responses API 的 `store=False` 参数。Kimi 对请求数据的保存、日志和训练处理以 Moonshot 平台当时生效的服务条款与隐私政策为准。

使用 OpenAI 时，请求通过 Responses API 发送并设置 `store=False`，项目不使用云端 Conversations 保存客户对话。无论选择 Kimi 还是 OpenAI，云端回答都必须经过本地命盘事实和非绝对化规则校验，否则自动回退为本地规则回答。

云端失败时，本地完整回答仍可使用。系统不会在同一次请求内自动重试；客户主动重试会产生新的一次 API 调用。

## 用户如何控制资料

用户可以随时进入“隐私与清除”，点击“立即清除我的资料”；AI 问答页也可单独清空对话。清除或会话过期后，如需再次分析，需要重新输入资料。

## 下载与日志

报告只在用户主动点击时生成下载，公网文件名不含称呼、生日或地点，服务器不保存下载副本。匿名技术日志保存 30 天，仅包含问题类别、模型别名、耗时档位和回退原因代码，不记录提问、回答、命盘事实、出生资料、联系方式或密钥。

## 使用边界

命数研究室提供传统文化研究与个人规划参考，不构成医疗、法律、投资或婚姻决定，也不构成借贷建议。
