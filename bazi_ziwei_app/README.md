# 命数研究室

命数研究室是一个以本地「四柱八字分析规则」为唯一命理判断规范的八字 + 紫微斗数工具。`lunar_python` 只用于公农历转换和精确节气数据；四柱、起运、强弱、格局、财运和姻缘结论由项目自有规则引擎显式产生。

## 本机服务地址

本程序统一使用以下地址：

```
http://127.0.0.1:8501
```

如果无法打开，请检查端口是否被占用：

```bash
lsof -i :8501
```

如果端口被占用，请释放：

```bash
lsof -ti :8501 | xargs kill -9
.venv/bin/python -m streamlit run app.py --server.port 8501
```

## AI 问答配置

AI 问答默认使用 Kimi K3；如果没有配置密钥，仍可使用本地四柱规则生成完整回答，但页面会明确提示云端服务不可用。

### 本机 Kimi K3

复制 `.streamlit/secrets.toml.example` 为 `.streamlit/secrets.toml`，
只把自己的 Kimi 开放平台 Key 填入本机文件。真实 secrets 文件已被 Git 忽略。

### 服务器部署

```bash
export MINGSHU_AI_PROVIDER="kimi"
export MOONSHOT_API_KEY="your-server-side-key"
export MINGSHU_AI_MODEL="kimi-k3"
export MINGSHU_AI_BASE_URL="https://api.moonshot.cn/v1"
export MINGSHU_AI_REASONING="low"
export MINGSHU_AI_TIMEOUT_SECONDS="90"
```

服务器环境变量优先于本机 secrets。网页不读取、不显示密钥。云端每个问题只调用一次，只返回自然分析正文；命盘证据和规则证据由本地装配。SDK 不自动重试，单次等待上限为 90 秒。云端负责理解问题和组织自然语言，本地“四柱八字分析规则”仍是命盘事实与校验的唯一规范来源。

云端回答会按本地 `AnalysisPlan` 分段校验。单段引用错误、事实冲突或漏答时，仅该段使用本地四柱规则结论替换；其他合格云端段落继续保留。只有当没有任何云端段落可安全使用时，才显示本地完整答案。诊断日志只记录匿名失败代码，不保存问题、回答、命盘或出生资料。

### AI 问答的使用与隐私边界

- AI 问答仅支持当前四柱相关问题；紫微斗数和其他术数不在当前 AI 问答范围内。
- 云端只接收与问题有关的去身份化事实包、本地结论计划和必要会话摘要；必要会话摘要最多取最近六条清理后的对话。
- 原始生日、姓名、地点、联系方式和密钥不会发送给 Kimi；经度、档案编号和内部版本也不会发送。
- 本次会话 30 分钟无操作后清除；匿名技术日志保存 30 天，且不记录提问、回答、命盘事实或出生资料。
- 云端失败时，本地完整回答仍可使用。系统不在同一次请求内自动重试；客户主动重试会产生新的一次 API 调用。
- 命理内容只供传统文化研究和个人规划参考，不构成医疗、法律、投资或婚姻决定。

## 常见问题

- 如果页面打不开，先确认终端里程序仍在运行。
- 如果提示缺少 Streamlit、pandas 或 lunar_python，请运行 `.venv/bin/python -m pip install -r requirements.txt`。

- “报告导出”页面支持综合报告 Markdown、TXT、PDF。
- “专项报告”页面支持事业、财运、婚恋专项报告 Markdown、TXT、PDF。
- PDF 会优先嵌入可渲染中文字体；如遇字体或依赖问题，会返回中文提示，建议改用 Markdown/TXT。

## 事件库扩展前校验

继续扩展流月现实事件库前，请先运行证据链质量校验，避免新增事件变成“事件名称 + 泛化文案”的堆叠：

```bash
.venv/bin/python tools/validate_event_chain_quality.py
```

如需保存诊断报告：

```bash
.venv/bin/python tools/validate_event_chain_quality.py --output docs/reports/event_chain_quality_report.md
```

校验会检查传统命理依据、结构依据、宫位依据、现代生活映射、触发规则、置信度、反向降级条件、来源依据和重复相似度。缺来源、缺关键字段、证据数量不足或触发规则过弱的事件，不应进入高置信度 Top 事件。
