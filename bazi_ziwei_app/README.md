# 命数研究室

命数研究室是一个本机离线运行的八字 + 紫微斗数命理分析工具，技术路线为 Python、Streamlit、SQLite、JSON 规则库和 lunar_python。程序不需要账号，不上传数据，适合个人兴趣、传统文化研究和自我规划参考。

**当前版本：v1.0 RC**

---

## 功能列表

### 八字排盘
- 四柱八字基础排盘
- 纳音、旬空、十二长生、五行扩展数据
- 命宫、身宫、胎元、胎息
- 日主强弱引擎（得令 / 得地 / 得势 / 净评分）
- 喜用五行判断与细化解释
- 十神分析 + 十神词条详解（性格、职业、建议）
- 命盘类型分类（身强/身弱/中和、五行格局、十神格局、特殊组合）

### 大运流年
- 大运起运时间和阶段
- 每个大运的事业、财富、关系、风险、建议分段
- 未来十年流年速览
- 年度运程（总览、关键词、四维度专项分析、评分图、高关注月份、机会月份）
- 12 个月流月分析（大概率事件、地支关系、五行提示、行动建议）

### 紫微斗数（基础版）
- 命宫、身宫、十二宫位
- 十四主星含义速查
- 紫微基础报告
- 注意：当前版本不伪造十四主星落宫，标记为后续增强方向

### 专项报告
- 事业专项报告
- 财运专项报告
- 婚恋专项报告
- 支持 Markdown、TXT、PDF 三种导出格式

### 数据管理
- SQLite 命盘本地存档
- 命盘搜索、编辑、重新排盘
- JSON 导出 / 导入
- SQLite 数据库备份

### 页面功能
- 综合问盘：一屏查看所有核心数据
- 五行喜忌：五行能量轮盘 + 十神分布
- 合婚匹配：双人命盘对比分析
- 报告导出：Markdown、TXT、PDF 三种格式
- 命盘档案：搜索、编辑、重排、删除
- 数据备份：JSON 导入导出、SQLite 备份
- 设置：报告长度、默认格式、质量检查等

### 视觉设计
- 淡雅东方调设计系统（茶色基底、墨色与藤黄）
- 全部页面卡片化布局
- 五行动画轮盘（SVG 粒子、呼吸光晕、双重旋转抵消）
- 大运走势图、年度评分图
- 自定义侧边栏导航

## 安装方式

```bash
# 创建虚拟环境
python -m venv .venv

# 激活虚拟环境
source .venv/bin/activate

# 安装依赖
python -m pip install -r requirements.txt

# 检查环境
python check_env.py
```

运行 `check_env.py` 会检查 streamlit、pandas、lunar_python 是否可导入。

---

## 启动方式

```bash
# 激活虚拟环境
source .venv/bin/activate

# 启动
python -m streamlit run app.py
```

打开浏览器访问 http://127.0.0.1:8501

macOS 也可双击 `start.command` 或运行 `bash run_mac.sh` 一键启动。

## 快速开始

1. **新建命盘**：点击「新建命盘」，输入姓名、性别、出生日期和时间
2. **查看排盘**：切换到「八字排盘」页面查看四柱八字的完整信息
3. **五行分析**：进入「五行喜忌」查看五行强弱和日主喜忌
4. **年度运程**：在「年度运程」页面选择年份查看详细分析
5. **导出报告**：进入「报告导出」，支持 Markdown / TXT / PDF
6. **保存命盘**：生成命盘后点击「保存命盘」即可存档

---

## 如何重新排盘

在「命盘档案」中选择已保存的命盘：
1. 点击「加载到当前命盘」进入当前工作区
2. 在「重新排盘」区域修改出生时间、性别等信息
3. 勾选确认框后点击「重新排盘」
4. 系统会自动覆盖原命盘结果

---

## 如何导出报告

### 综合报告导出
进入「报告导出」页面，三种格式可选：
- **Markdown**：适合阅读、复制、分享
- **TXT**：适合纯文本查看
- **PDF**：适合保存和打印（优先嵌入本机中文字体）

### 专项报告导出
进入「专项报告」页面，选择事业 / 财运 / 婚恋，同样支持 Markdown、TXT、PDF。

---

## 如何备份和恢复数据

### 备份
进入「数据备份」页面：
- 点击「导出所有命盘 JSON」→ 下载可迁移备份文件
- 点击「备份 SQLite 数据库」→ 在本机创建数据库副本

### 恢复
- 在「数据备份」页面上传 JSON 文件，确认后导入
- 通过 SQLite 备份文件手动恢复（替换 `data/profiles.db`）

## 已知限制

- 统一使用北京时间（东八区），不支持真太阳时自动校正
- 紫微斗数为主星含义速查 + 宫位分析，不含主星落宫
- PDF 导出依赖 reportlab，需本机有合适的中文字体
- 数据仅保存在本地 SQLite，不支持云同步

## 常见问题

**Q：页面打不开？**
确认终端中 `streamlit run app.py` 仍在运行，访问 http://127.0.0.1:8501

**Q：提示缺少依赖？**
运行 `python -m pip install -r requirements.txt`

**Q：PDF 导出失败？**
当前环境可能缺少中文字体或 PDF 依赖，请改用 Markdown 或 TXT 导出

**Q：数据库异常？**
在「数据备份」页面使用 JSON 导出文件或 SQLite 备份恢复
