# 财务收入事件触发链差异化报告 v1.0.4.4

本轮没有扩展事件总数，只处理诊断报告中最容易重复的六个财务收入类事件：

- `client_payment`：客户回款
- `sales_conversion`：客户成交
- `salary_bonus`：工资奖金
- `commission_income`：佣金提成
- `side_income`：副业收入
- `business_cash_in`：经营现金流进入

## 拆分后的判断重点

| 事件 | 新触发主轴 | 现实场景 |
|------|------------|----------|
| 客户回款 | 财星、日支/合作方、土库账期、凭证流程 | 尾款、旧账、账期推进 |
| 客户成交 | 食伤表达、桃花人缘、报价询盘、客户入口 | 新客户、报价反馈、询盘转订单 |
| 工资奖金 | 官杀考核、印星流程、月支事业平台 | 绩效奖金、补贴、调薪 |
| 佣金提成 | 食伤销售、财星收益、比劫分成边界 | 提成、代理佣金、业绩归属 |
| 副业收入 | 食伤技能输出、时支副线项目 | 兼职、小项目、内容/技能变现 |
| 经营现金流 | 财星流水、月支经营环境、土库账目 | 门店流水、批量收款、周转 |
