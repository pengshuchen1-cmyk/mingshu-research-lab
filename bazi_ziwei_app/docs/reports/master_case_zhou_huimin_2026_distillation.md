### 1-2 月：节点日、小心出行、忽然变化、压抑和 110

用户确认原文：2号、12号、22号小心出行，忽然变化，压抑，110。

这段不是单看出行，而是把节点日、临时变化、压抑感和规则/安全警告放在同一条风险链里。系统应映射为：

- `travel_traffic`：出行、路程、通勤或外出事项
- `safety_attention`：出门小心、工具或交通安全提醒
- `travel_delay`：忽然变化、路线变更、行程延误
- `official_dispute` / `rule_penalty` / `legal_compliance`：110、规则、报警边界、纠纷或处罚提醒
- `impulsive_decision`：变化来得快时不宜冲动处理
- `emotional_pressure`：压抑、压力和情绪消耗

蒸馏结论：110 不能写成恐吓，应安全转译为规则边界、报警边界、纠纷、处罚或安全提醒。节点日适合作为“重点留意日”，但不能写成确定事件。

### 3-4 月：有项目、不投资、买房买车信号

用户确认原文：有项目，不投资，有买房买车的信号。

这段同时出现项目机会与资产物象，但师傅明确强调“不投资”，说明机会和资产动作要分开看。系统应映射为：

- `project_progress`：项目推进或业务事项出现
- `business_negotiation`：项目沟通、报价、商务谈判
- `investment_risk`：不适合贸然投资
- `cashflow_pressure`：投资或置办前要先看现金流承载
- `asset_purchase`：大件资产、置物计划
- `property_housing`：买房、看房、居住事务
- `vehicle_expense`：买车、看车、车辆支出
- `family_asset`：家庭资产或固定资产安排

蒸馏结论：有项目不等于适合投钱；买房买车也不等于确定购买，而是房、车、大件资产和长期成本信号被点亮。

### 5-6 月：情感问题、被套住、焦虑

用户确认原文：情感问题，被套住，焦虑。

这段是关系、现实束缚和情绪压力叠加。系统应映射为：

- `relationship_conflict`：关系摩擦、情感问题
- `misunderstanding`：误会解释、沟通卡点
- `relationship_progress`：关系仍有推进或确认空间
- `cashflow_pressure` / `investment_risk`：被套住也可能对应资金、合作或现实安排难抽身
- `delayed_issue`：拖住、延后、不易推进
- `emotional_pressure` / `fire_anxiety`：焦虑、心火、状态紧绷

蒸馏结论：被套住不是单纯感情，也可能是钱、合作、承诺或现实安排卡住。系统输出应提示“先降温、先核实、先留退路”。

- `family_issue`：亲人事、家庭事务

- `contract_document` / `approval_process`：签字、合同、审批、确认
- `business_surprise`：有奇迹感或项目转机
- `business_partnership` / `cooperation_opportunity`：合作机会

蒸馏结论：奇迹感可以作为转机提示，但“留余地、短合”说明合作宜阶段性推进，签字前尤其要看责任、时间和退出条件。

## 可沉淀到系统的分析链

### 节点日 + 出行 + 规则警告

当节点日、出行、忽然变化和 110 同段出现时，优先生成“出行安全 + 规则边界 + 留证据”的组合提醒。

### 项目 + 不投资 + 房车信号

有项目时仍可能不适合投钱。房车信号应解释为资产、车辆、大件置办和长期成本，不应直接说确定购买。

### 情感问题 + 被套住 + 焦虑

关系、资金、合作和承诺可能互相牵制。系统要提示先理清现实责任，再处理情绪和关系推进。

### 亲人责任 + 签字 + 短合

家庭责任和合作文书同段出现时，要把签字、审批、合同、短期合作、退出条件作为重点。

### 闺蜜亲友 + 车酒 + 办业务

朋友亲友、车辆、酒局和业务流程同段出现时，系统不应只说社交，而要同时给出出行、安全、资料、凭证和身体状态建议。

### 子女事 + 内耗 + 太太包容

子女事先按家庭责任和长期规划处理；太太包容按伴侣关系和情绪管理处理；内耗按工作卡点和过劳状态处理。
