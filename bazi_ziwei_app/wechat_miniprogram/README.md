# 命数研究室微信小程序测试版

这是原项目的原生微信小程序适配层。小程序负责移动端界面与交互，本机 `miniapp_api` 继续调用原有 Python 核心，因此没有另写一套简化算法。

## 已映射功能

- 今日/年度大众建议、新建/编辑命盘、四柱预览
- 八字排盘、命盘总览、五行喜忌、六十甲子、大运流年、年度运程与十二个月
- 事业、财运、婚恋专项报告，紫微十二宫与说明书
- AI 命理问答与近 20 条会话历史
- Markdown、TXT、PDF 报告导出
- 命盘保存、搜索、加载、编辑重排与删除
- 合婚匹配、JSON 备份/恢复、SQLite 数据库备份
- 设置、固定样例验收、隐私说明与会话清除

## 1. 启动本地 API

在 `bazi_ziwei_app` 目录运行：

```bash
.venv/bin/python -m pip install -r requirements.txt
bash run_miniapp_api.sh
```

看到 `Uvicorn running on http://0.0.0.0:8502` 后，可访问：

- 健康检查：`http://127.0.0.1:8502/api/health`
- 接口文档：`http://127.0.0.1:8502/docs`

## 2. 在微信开发者工具中导入

1. 选择“导入项目”。
2. 项目目录选择本文件所在的 `wechat_miniprogram` 文件夹。
3. 暂无小程序 AppID 时使用测试号/游客模式；项目已预填 `touristappid`。
4. 在开发者工具的本地设置中保持“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。项目配置中也已关闭 URL 校验。
5. 编译后先进入“我的 → 测试与报告设置”，点击“测试连接”。

桌面模拟器默认 API 地址：

```text
http://127.0.0.1:8502/api
```

## 3. 真机局域网测试

真机上的 `127.0.0.1` 指手机自身，不能连接电脑。请确保手机和电脑在同一局域网，然后：

1. 在电脑终端运行 `ipconfig getifaddr en0` 获取局域网 IP，例如 `192.168.1.20`。
2. 在小程序“我的 → 测试与报告设置”把服务地址改为 `http://192.168.1.20:8502/api`。
3. 点击“测试连接”。若失败，检查 macOS 防火墙是否允许 Python 接收入站连接。

该方式只适合本地/局域网测试。正式发布时需要 HTTPS API、已备案且配置到微信后台的合法域名、持久化会话与相应隐私合规配置。

## 建议验收顺序

1. 首页和“今日”页可加载。
2. 新建命盘，先看四柱预览，再确认生成。
3. 在“命盘”页逐一打开八字、五行、大运、年度、专项和紫微页面。
4. 在“问答”页验证本地规则回答；如本机配置了 Kimi，再验证云端回答。
5. 保存两份档案，验证档案编辑、合婚、报告 PDF 与备份恢复。
6. 在不同屏幕尺寸模拟器检查文字换行、横向四柱卡片和底部安全区。

## 数据与测试边界

- 当前会话在 API 内存中保存，30 分钟无操作后清除；服务重启也会清除。
- 只有主动保存时才写入原项目 `data/profiles.db`。
- JSON 导入与原版行为一致：新增通过校验的档案记录，不自动覆盖已有档案。
- 小程序和网页版可以同时运行：网页版 8501，小程序 API 8502。
