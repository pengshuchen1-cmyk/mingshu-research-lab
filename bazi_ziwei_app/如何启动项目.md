# 如何启动命数研究室

## 🚀 方式一：一键启动（推荐）

在终端执行：

```bash
cd /Users/hongzezhang/workspace/mingshu-research-lab/bazi_ziwei_app
bash start.sh
```

脚本会自动：
1. ✅ 创建虚拟环境（如果不存在）
2. ✅ 安装所有依赖
3. ✅ 启动服务
4. ✅ 自动打开浏览器

**访问地址：** http://127.0.0.1:8501

**停止服务：** 按 `Ctrl + C`

---

## 📋 方式二：手动启动（分步骤）

### 第 1 步：创建虚拟环境

```bash
cd /Users/hongzezhang/workspace/mingshu-research-lab/bazi_ziwei_app
python3 -m venv .venv
```

### 第 2 步：激活虚拟环境

```bash
source .venv/bin/activate
```

激活后，终端提示符前会出现 `(.venv)`

### 第 3 步：安装依赖

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

首次安装需要 1-2 分钟，会安装以下包：
- streamlit (Web 框架)
- pandas (数据处理)
- lunar_python (公农历转换)
- reportlab (PDF 导出)
- openai (AI 接口)
- pydantic (数据验证)

### 第 4 步：启动服务

```bash
streamlit run app.py --server.port 8501
```

看到以下输出表示启动成功：

```
You can now view your Streamlit app in your browser.

  Local URL: http://localhost:8501
  Network URL: http://192.168.x.x:8501
```

### 第 5 步：访问应用

浏览器自动打开，或手动访问：

**http://127.0.0.1:8501**

## 🛠️ 常见问题

### 问题 1：提示 `command not found: python3`

**解决方法：** 安装 Python

```bash
# macOS (使用 Homebrew)
brew install python@3.11

# 或下载官方安装包
# https://www.python.org/downloads/
```

---

### 问题 2：提示 `No module named 'streamlit'`

**原因：** 依赖未安装或虚拟环境未激活

**解决方法：**

```bash
# 1. 确保已激活虚拟环境
source .venv/bin/activate

# 2. 重新安装依赖
pip install -r requirements.txt

# 3. 验证安装
pip list | grep streamlit
```

---

### 问题 3：端口 8501 被占用

**错误信息：**
```
OSError: [Errno 48] Address already in use
```

**解决方法：**

```bash
# 查看占用进程
lsof -i :8501

# 杀死进程
lsof -ti:8501 | xargs kill -9

# 或使用不同端口
streamlit run app.py --server.port 8502
```

---

### 问题 4：提示 `ModuleNotFoundError: No module named 'ui'`

**原因：** 没有在项目根目录启动

**解决方法：**

```bash
# 确保在正确的目录
cd /Users/hongzezhang/workspace/mingshu-research-lab/bazi_ziwei_app

# 然后再启动
streamlit run app.py
```

---

### 问题 5：页面打不开或一直加载

**解决方法：**

```bash
# 1. 清除 Streamlit 缓存
rm -rf ~/.streamlit/

# 2. 重启服务
# 按 Ctrl+C 停止
# 然后重新运行 start.sh
```

## 🔧 高级配置

### 配置 AI 问答（可选）

如果要使用 AI 问答功能，需要配置 Kimi API Key：

#### 方法 1：使用配置文件

```bash
# 1. 复制示例配置
cp .streamlit/secrets.toml.example .streamlit/secrets.toml

# 2. 编辑配置文件
nano .streamlit/secrets.toml
```

在文件中填入你的 API Key：

```toml
MOONSHOT_API_KEY = "sk-你的密钥"
MINGSHU_AI_PROVIDER = "kimi"
MINGSHU_AI_MODEL = "kimi-k3"
```

保存后重启服务。

#### 方法 2：使用环境变量

```bash
export MOONSHOT_API_KEY="sk-你的密钥"
export MINGSHU_AI_PROVIDER="kimi"
export MINGSHU_AI_MODEL="kimi-k3"

# 然后启动
streamlit run app.py
```

**注意：** 
- 不配置 AI 密钥也能正常使用，只是 AI 问答功能会降级为本地规则回答
- 密钥文件不会被提交到 Git（已加入 .gitignore）

---

### 切换运行模式

#### 本地模式（默认）- 保存命盘数据

```bash
export MINGSHU_RUNTIME_MODE=local
streamlit run app.py
```

**特点：**
- ✅ 命盘保存到数据库
- ✅ 支持命盘档案功能
- ✅ 支持数据备份

#### 公网模式 - 不保存数据

```bash
export MINGSHU_RUNTIME_MODE=public
streamlit run app.py
```

**特点：**
- ✅ 不保存命盘到数据库
- ✅ 会话 30 分钟失效
- ✅ 适合公网部署
