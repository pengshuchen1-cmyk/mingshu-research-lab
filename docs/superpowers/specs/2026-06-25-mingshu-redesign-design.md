## 一、设计系统

### 1.1 色调

| 角色 | 色值 | 用途 |
|------|------|------|
| 基底色 | #F5F0EB | 页面全局背景 |
| 卡片底色 | #FAF7F4 | 卡片 / 容器背景 |
| 墨色 | #3D2B1A | 标题、正文主色 |
| 次墨 | #5C4A32 | 次要文字 |
| 藤黄（强调） | #B8860B | 强调色、高亮、关键数值 |
| 浅金 | #D4A843 | 装饰、点缀 |
| 土茶 | #8C7A64 | 辅助文字、说明 |
| 分界线 | #EDE6DC | 分割线、边框 |
| 朱砂（警示） | #B85C4A | 错误、警示信息 |

五行配色（图表用）：
| 五行 | 色值 | 场景 |
|------|------|------|
| 木 | #8BA888 | 木属性相关 |
| 火 | #B85C4A | 火属性相关 |
| 土 | #C4A882 | 土属性相关 |
| 金 | #D4A843 | 金属性相关 |
| 水 | #7A9BAE | 水属性相关 |

### 1.2 字体

- **标题字体**：Noto Serif SC（思源宋体），用于页面标题、四柱天干地支
- **正文字体**：Noto Sans SC（思源黑体），用于正文、数据、标签
- **后备**：PingFang SC / -apple-system
- **字号层级**：页面标题 28px → 章节标题 20px → 卡片标题 16px → 正文 14px → 辅助 12px

### 1.3 卡片系统

- 圆角 10px，背景 #FAF7F4
- 阴影：`0 1px 3px rgba(0,0,0,0.06), 0 1px 2px rgba(0,0,0,0.04)`
- 内边距：16-20px
- 层级分类：
  - **指标卡**：标题 + 大号数值 + 简短说明（三列一行）
  - **信息卡**：键值对行排列（如用户信息、五行详情）
  - **图表面板**：图表 + 标题
  - **展开卡**：可展开的详细内容容器

### 1.4 标签系统

五行标签带各自专属色，圆角 12px：
- 木：#8BA888 底 / 火：#B85C4A 底 / 土：#C4A882 底 / 金：#D4A843 底 / 水：#7A9BAE 底

十神标签使用统一浅色底 + 次墨文字。

### 1.5 导航侧边栏

- 背景色 #3D2B1A（墨色），文字 #B8A894
- 当前页面高亮：背景 #B8860B，文字 #FCF8F0
- hover 效果：背景 rgba(255,255,255,0.06)
- 导航项从 14 项精简合并为约 11 项

## 二、页面结构改造

### 2.1 导航重组

**合并**：五行十神 + 日主喜忌 → **「五行喜忌」**

**精简后导航顺序**：
首页 → 新建命盘 → 八字排盘 → 综合问盘 → 五行喜忌 → 大运流年 → 年度运程 → 专项报告 → 紫微斗数 → 命盘档案 → 设置

### 2.2 全局 CSS 注入

- 创建 `ui/styles.py`，封装全局 CSS
- 在 `app.py` 入口注入 CSS
- 覆写按钮、输入框、选择框、度量值等默认样式
- 自定义卡片、标签、网格样式
- 导航侧边栏自定义背景和文字颜色

### 2.3 页面改造细则

**首页**：标题 + 副标题 → 指标卡（日主/强弱/命盘数）→ 最近命盘卡片

**新建命盘**：表单放入卡片容器，应用自定义输入样式

**八字排盘**：
- 四柱：4 列网格卡片（天干大号宋体 + 地支 + 十神）
- 补全：藏干 + 十神标注、空亡、纳音
- 总览：指标卡（日主/强弱/净评分）
- 基础信息卡：姓名、性别、生日、农历
- 喜忌：五行色标签
- 详细文本使用展开卡

**综合问盘**：信息卡分组，快速导航链接

**五行喜忌（合并）**：
- 顶部五行彩色卡片（保留现有布局）
- 环图 + 柱状图（Altair，配色调整）
- 强弱水平条 + 日主强弱指标卡
- 喜用五行标签 + 展开卡
- 十神水平条 + 数据表
- 五行/十神解说文本

**大运流年**：
- 起运信息 3 指标卡
- 当前大运高亮卡片
- 大运走势图（Plotly，柱状）
- 大运表 + 各阶段 expander
- 流年速览表

**年度运程**：评分指标卡 → 雷达图（Plotly）→ 月卡片

**紫微斗数**：4x3 网格宫位卡片

**其余页面**：统一卡片布局，统一按钮/表单样式

## 六、技术约束

- Streamlit CSS 通过 `st.markdown` 注入 `<style>`
- 导航通过 `st.sidebar`，CSS 覆写样式
- Plotly 通过 `st.plotly_chart()`，Altair 通过 `st.altair_chart()`
- 卡片布局通过 `st.columns()` + `st.container()` + 自定义 CSS
- 中文字体使用系统字体
