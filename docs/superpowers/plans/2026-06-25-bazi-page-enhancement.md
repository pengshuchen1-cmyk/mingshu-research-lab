# 八字排盘页增强 · 实施计划

**Goal:** 对标测测 app，完善八字排盘页面的信息密度和展示格式

**Architecture:** 引擎层补全数据 → 新增词条和分类模块 → 页面层重构

**Tech Stack:** lunar_python + Streamlit + 自定义 CSS

## 全局约束

- 不修改已有的 strength_engine 核心逻辑
- 十神词条、命盘分类使用独立模块（`core/ten_god_explanations.py`, `core/chart_type.py`）
- 新的 lunar_python 数据扩展在 `core/calendar_engine.py` 和 `core/bazi_engine.py` 中做加法
- 设计语言延续已有的设计系统（淡雅东方调）

### Task 1: 引擎数据补全 — lunar_python 扩展

**Files:**
- Modify: `core/calendar_engine.py`
- Modify: `core/bazi_engine.py`

**新增字段（从 lunar_python EightChar 提取）：**

每柱新增：
- `na_yin` — 纳音（如"大林木"），来自 `getYearNaYin()` 等
- `xun_kong` — 旬空（空亡，如"戌亥"），来自 `getYearXunKong()` 等
- `di_shi` — 十二长生（如"长生"、"沐浴"），来自 `getYearDiShi()` 等
- `wu_xing` — 五行（如"金"），来自 `getYearWuXing()` 等

全局新增：
- `ming_gong` — 命宫，来自 `getMingGong()`
- `shen_gong` — 身宫，来自 `getShenGong()`
- `tai_yuan` — 胎元，来自 `getTaiYuan()`
- `tai_xi` — 胎息，来自 `getTaiXi()`

**修改 calendar_engine.py：**
在 `get_lunar_eight_char()` 函数中，为每个柱子提取纳音、旬空、十二长生、五行。

**修改 bazi_engine.py：**
在 `build_bazi_chart()` 函数中，将新增字段写入 chart 字典。

### Task 3: 命盘类型分类模块

**Files:**
- Create: `core/chart_type.py`

基于已有数据（日主强弱、五行分布、十神统计）做规则分类。

**分类维度：**

1. 基本格局（基于日主强弱）：
   - 身强格、身弱格、中和格

2. 五行格局（基于五行分布）：
   - 五行俱全、缺某行偏旺某行

3. 十神格局（基于计数最多的十神类型）：
   - 财旺格（正财+偏财 最多）
   - 官杀格（正官+七杀 最多）
   - 印旺格（正印+偏印 最多）
   - 食伤格（食神+伤官 最多）
   - 比劫格（比肩+劫财 最多）

4. 特殊组合：
   - 杀印相生（七杀在天干 + 正印/偏印在天干）
   - 食神生财（食神 + 偏财/正财同时出现）
   - 伤官配印（伤官 + 正印/偏印）
   - 官杀混杂（正官 + 七杀同时出现）

输出格式：
```python
{
    "basic_pattern": "身强格",
    "element_pattern": "缺金",
    "ten_god_pattern": "食伤格",
    "special_combinations": ["杀印相生"],
    "summary": "身强食伤格，适合通过才华和技术创造价值。"
}
```

### Task 4: 八字排盘页面重构

**Files:**
- Modify: `ui/bazi_page.py`
- Modify: `ui/styles.py`（如有需要添加新的 CSS）

**页面布局（自上而下）：**

#### 4.1 基础信息区
- 姓名、性别、公历生日、农历 → 改为一行精简展示

#### 4.2 四柱八字卡片（核心）
四列并排，每柱一个信息丰富的卡片：

```
┌──────────────┐
│   年柱        │  ← 柱名（小字，#8C7A64）
│   庚          午 │  ← 天干地支（大号26px宋体）
│ 大林木        │  ← 纳音（小字，#B8860B）
│ 七杀 │ 藏干   │  ← 十神标注
│ 藏：己(正印)  丁(偏财) │  ← 藏干+十神（小字）
│ 空亡：戌亥    │  ← 空亡（小字，#8C7A64）
│ 帝旺          │  ← 十二长生（小字）
└──────────────┘
```

- 日柱卡片：金色边框（`2px solid #B8860B`）+ "日主"标记
- 每个卡片所有信息直接展示（不需展开）
- 藏干用五行色小标签

#### 4.3 日主总览区

#### 4.5 命宫/身宫/胎元/胎息 信息卡

#### 4.6 五行能量条（可视化）

#### 4.7 十神分布 + 十神词条
